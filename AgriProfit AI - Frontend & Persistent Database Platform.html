AgriProfitDB (Version 1) — Schema & Indexes

4 Normalized Object Stores with Auto-Increment Primary Keys & Indexed Lookups

1. farm_plans

  • PK: id (autoIncrement)
  • farmName, state, acres
  • soil, water, budget
  • cropName, investment, expenses
  • netProfit, roi, risk, status
  • IDX: state, status, createdAt

2. farmers

  • PK: id (autoIncrement)
  • name, email, phone
  • state, acres, planTier
  • twoFactorEnabled (bool)
  • IDX: email, state

3. inquiries

  • PK: id (autoIncrement)
  • type (Booking / Contact)
  • name, phone, location
  • details, status
  • IDX: type, status

4. security_logs

  • PK: id (autoIncrement)
  • eventType, severity
  • details, timestamp
  • IDX: severity, timestamp
